# 第1章　エグゼクティブサマリー

IP事業部では現在、新人が初稼働するまでに平均82.7日かかっており、入社3ヶ月以内の継続率は37.5%（24人中9人のみ定着）にとどまる。育成が先輩の時間と経験に依存しているため、品質がバラつき、採用を増やしても成果につながりにくい構造になっている。

本提案は、LINEを活用したAI新人コーチを構築することでこの課題を根本から解決する。初稼働を82.7日から51日へ短縮（38%削減）し、継続率・育成品質の均一化・先輩の工数削減を同時に実現する。

4ヶ月・240時間（社内開発）で本番稼働。将来的にはApp Storeへの外部展開・SaaSビジネス化も視野に入れる。

# 第3章　現状の課題

## 数字で見る現状

| 指標 | 現状 |
|------|------|
| 平均初稼働日数 | 82.7日 |
| 入社3ヶ月継続率 | 37.5%（24人中9人） |
| 先輩の育成工数 | まちまち・属人的・測定困難 |
| スクリプト合格率（初回） | 測定なし |

## 課題の内訳

【課題①】初稼働までに時間がかかる
・先輩の都合次第でしか練習できない
・教え方・基準が人によってバラバラ
・どこで詰まっているか管理者に見えない
・待ち時間・スケジュール調整で日数が膨らむ

【課題②】先輩・管理者の工数が大きい
・練習相手：先輩が営業時間を育成に割く必要がある
・テスト採点：管理者が個別に対応
・進捗確認：誰がどこまで進んでいるか把握しにくい
・基準の統一：教える人によってバラつきがある

【課題③】継続率が低い（37.5%）
・初稼働が遅いため収入が入るまでの期間が長く離脱しやすい
・練習できずモチベーションが下がる
・育成の孤独感（誰に聞けばいいかわからない）

【課題④】スケールしない
採用人数が増えるほど育成コストが比例して増大する。
人に依存した育成では限界がある。

# 第4章　プロダクト概要

## 4-1. ビジョン

「入社した日から、AIが隣にいる。初稼働まで一人でも・最速で・確実に辿り着ける。」

LINE Bot（新人用）＋ Web管理画面（管理者用）

素材1：メインスクリプト
　インターホントーク〜クロージング・同意書まで

素材2：FAQ・アウト返し
　よくある質問・断り文句への切り返し13項目

素材3：同意書後フロー
　同意書通過後トーク〜ネガキャントーク〜受付書入力後トーク〜退出時トーク

素材4：後確〜完結フロー
　後確後トーク〜解除トーク〜解除アポ組むトーク〜今後の流れトーク〜開通後押しトーク

| # | 範囲 | 練習方法 |
|---|------|---------|

## AI練習のお客さんパターン（練習時に選択）

## 機能1｜スクリプト学習モード

内容：全4カテゴリのスクリプトを読んで理解・暗記する

ツール：LINE Messaging API

## 機能2｜AI練習モード（テキスト）

内容：AIがお客さん役になってスクリプトを練習する
方法：LINEのチャットでロールプレイ
　　　お客さんパターン（A〜E）を選択して開始
　　　練習終了後に自動でフィードバック生成

フィードバック内容：
　・総合スコア（100点満点）
　・よかった点（具体的に）
　・改善点（抜けたセリフ・えーあのーの回数・スピード等）
　・次の練習で意識すること（1点に絞って提示）

ツール：LINE Messaging API ＋ Claude API

## 機能3｜AI練習モード（音声）

内容：実際に声に出してスクリプトを練習する
方法：スマホのマイクで録音→LINEで送信→文字起こし→AI分析→フィードバック
　　　話すスピード・言葉の抜け・えーあのーの回数・声のトーンも評価
ツール：LINE Messaging API ＋ Whisper API ＋ Claude API

## 機能4｜テストモード（テスト1〜3）

内容：テスト1〜3をオンラインで実施し、管理者が合否を登録する
方法：
　①新人がオンライン（ビデオ通話等）でスクリプトを通す
　②管理者がWeb管理画面（/admin/users/ID）の「合格にする」ボタンを押す
　③合格登録と同時に新人のLINEへ通知・進捗ステップ・チェックリストが自動更新

LINEで「テスト」と送ると現在の合否状況（テスト1〜3）が表示される。

ツール：LINE Messaging API ＋ Next.js（管理者Web）＋ PostgreSQL

## 機能5｜暗記練習モード（アウト返し・同意書後・後確）

内容：テスト4〜6相当の内容をAIとロールプレイで練習する
方法：LINEで「暗記」→3カテゴリから選択→AIとロールプレイ→「練習終了」で終了

カテゴリ：
　・アウト返し：AIが断り文句を仕掛けてくる・切り返し練習
　・同意書後〜退出：同意書記入後から退出までの対応練習
　・後確〜今後の流れ：後日確認の電話から今後の説明練習

ツール：LINE Messaging API ＋ Groq API（llama-3.3-70b）

内容：スクリプト練習・書類記入の手順を動画で確認できる

## 機能8｜進捗管理・チェックリスト＋可視化

内容：13項目進捗・今日やること・推定初稼働日・同期比較・過去データ比較

【毎朝の自動プッシュ通知】
　📅 入社14日目
　🎯 テスト3開始から3日目
　⏱️ 推定初稼働まであと21日
　📌 今日やること：テスト3通し練習を3回やろう

# 第9章　期待される効果

## 9-1. 初稼働日数の短縮

| フェーズ | 現状 | AI導入後 | 変化理由 |
|---------|------|---------|---------|
| スクリプト学習・練習 | 約15日 | 5日 | 24時間練習可能・動画で即理解 |
| テスト1 | 7日 | 4日 | 練習量増で合格率UP |
| テスト2 | 7日 | 4日 | 同上 |
| テスト3 | 10日 | 7日 | 同上 |
| MTG・見学・配属面談 | 約10日 | 10日 | 外部要因のため変わらない |

| 待ち・調整 | 約13日 | ほぼ0 | 進捗が常に明確になるため |

現状：82.7日 → AI導入後：約51日（約38%短縮・約32日短縮）

## 9-2. 継続率改善のメカニズム

現状37.5%の継続率が低い主な理由：
・初稼働が遅く収入が入るまでの期間が長い→離脱
・練習できずモチベーションが落ちる→離脱
・誰に何を聞けばいいかわからない孤独感→離脱

AI導入でこれが変わる：
・初稼働が32日早まる→32日早く収入が入る→離脱理由が減る
・24時間いつでも練習できる→モチベーションを維持しやすい
・毎朝「今日やること」が届く→孤独感・迷子感がなくなる
・スコアが伸びているのが見える→成長実感が継続を後押しする

目標：37.5% → 47.5%以上（+10ポイント）

## 9-3. 売上インパクト試算

```
初稼働が1人あたり32日早まる
年間採用10人 × 32日 ＝ 320人日分の稼働が前倒し

1人1日あたりの平均売上をXとすると
→ 年間で 320 × X円 の売上機会が回復する
```

# 第12章　リスクと対策

| リスク | 対策 |
|--------|------|
| スクリプトが変わった場合 | 管理者がWeb画面で内容を更新するだけで全員に即反映。クイズも自動更新。 |
| API障害・サーバー障害 | LINEで「サーバーが一時的に使えません」と自動通知。復旧後に継続可能。 |
| AIの採点精度が低い場合 | 管理者が採点基準を調整可能。不服がある場合は管理者が手動で合否を変更できる。 |
| 新人がLINEを使いこなせない場合 | 初回ログイン時に管理者がサポート。操作は「送る」だけのシンプル設計。 |
| 個人情報・データプライバシー | 練習内容・評価データは社内管理のみ。外部に共有しない設計。 |
| 動画素材が準備できない場合 | 動画なしでもテキスト・クイズのみで運用可能。動画は後から追加できる。 |
